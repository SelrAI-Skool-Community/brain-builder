# Seed material

Not the kit. These are the prior assets the build was reworked from, kept as history.

**Nothing in here is the install path.** `seed/topic-brain-builder/SETUP-PROMPT.md` is the old skill's own prompt and is superseded by [`SETUP-PROMPT.md`](../SETUP-PROMPT.md) at the repo root. Follow that one.

- `topic-brain-builder/` - Selr's earlier YouTube brain skill. Seeds the YouTube/yt-dlp ingestion arm. It is YouTube captions only; every other source in the v1 lineup (local files, PDF/EPUB, web, podcasts/RSS) is new build.
- `brain-toggle/` - prototype of the attach/detach skill that connects a built brain to an agent harness.
